# Projetos

Esta pasta reúne os primeiros projetos desenvolvidos durante o aprendizado de Python.  
Diferente dos exercícios básicos, os projetos simulam aplicações reais, com entrada, processamento e saída bem estruturados.

## Objetivo
- Consolidar os conceitos aprendidos em exercícios.  
- Criar programas completos e funcionais.  
- Evoluir gradualmente para projetos mais complexos.  

## Organização
Cada projeto está numerado (31, 32, 33...) e possui seu próprio arquivo Python.  
A tendência é que novos projetos sejam adicionados conforme o aprendizado avança.
